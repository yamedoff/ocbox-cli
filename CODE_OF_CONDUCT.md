# Code of conduct

We expect respectful, constructive, and inclusive collaboration in issues,
pull requests, reviews, and project spaces. Harassment, discrimination,
threats, doxxing, and publication of another person's private information are
not acceptable.

Give technical feedback about the work, assume good intent while asking for
clarity, and correct mistakes transparently. Maintainers may edit or remove
content and restrict participation when conduct harms the community.

Report conduct concerns privately to the repository owner using a private
contact method listed on their GitHub profile. Do not include sensitive details
in a public issue.
