# Security policy

This repository is a pre-release CLI foundation and does not yet implement
provider access, credentials, billing, or hosted operations.

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
private vulnerability reporting channel when it is available, or contact the
repository owner through a private method listed on their GitHub profile.
Include affected versions, reproduction steps, and impact without including
real credentials or customer data.

Only the current `main` branch is eligible for security fixes during the v0.1
foundation phase. No response or remediation timeline is promised yet.
